# Third-Party Notices

This file records third-party materials included in the Compass Suite public site.

## Current Public Site

No additional third-party notices are required for this public site beyond dependencies declared in package metadata or individual Compass release packages.

## Future Package Format

When a Compass package bundles third-party dependencies, models, datasets, design assets, documentation excerpts, or public-license materials, list them with:

- Source
- Version or commit
- License
- Included location
- Notes about modifications, generated files, bundled assets, or attribution requirements
