# Brand And Attribution

Working Tools by J. Kyle Hobson is the public directory for work created by Jonathan Kyle Hobson. Critical Compass, Prompt Compass, UX Heuristics Compass, UXHC, UXH Compass, and future Compass product names remain product identifiers inside that larger library.

The software and documentation licenses grant rights to use, study, modify, and share covered materials. They do not grant permission to imply endorsement, official status, or authorship by Jonathan Kyle Hobson for modified versions.

## Required Attribution

Redistributed packages and modified versions should include:

- The applicable license files.
- The `NOTICE` file.
- A visible attribution to Jonathan Kyle Hobson.
- A link to the official Working Tools page when practical.

Suggested short attribution:

> Based on Working Tools and Compass product work by Jonathan Kyle Hobson. This modified version is not an official release.

## Official Release Language

Use language like this only for releases published by Jonathan Kyle Hobson:

> Official [Product Name] release by Jonathan Kyle Hobson.

Use language like this for forks or modified versions:

> Unofficial fork of [Product Name], based on work by Jonathan Kyle Hobson.

## Reserved Brand Assets

The following are reserved unless a later file grants permission:

- The Working Tools mark and Compass product logos.
- Jonathan Kyle Hobson author photo.
- Official page design/trade dress where it could confuse users into thinking a fork is official.
- Product names used as the name of an unofficial modified product.

## Allowed Reference Use

You may truthfully say that your work is based on, compatible with, inspired by, or forked from a Compass project, as long as the wording does not imply endorsement or official release status.

## No Endorsement

Do not use Jonathan Kyle Hobson's name, image, or Compass product branding to imply approval, sponsorship, or review of a modified package unless written permission has been granted.
