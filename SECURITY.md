# Reporting a vulnerability

For a suspected security vulnerability in this repository, use [GitHub's private vulnerability report](https://github.com/JonathanKHobson/compass-suite/security/advisories/new). Include the affected URL or version, reproduction steps, and the observed impact. Do not post credentials or personal data in public issues.

For ordinary broken links or installation questions, use Issues. For another product's runtime, report to its owning repository. This directory distributes links and public artifacts; it does not establish support for every private integration described elsewhere.
