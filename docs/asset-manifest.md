The former editorial still-life image was removed. It did not explain the
library, clipped its caption in the rendered layout, and introduced an electric
lime accent that conflicted with the Humanizer-led system. New imagery is not a
default requirement: it must provide instruction, evidence, orientation, or a
product-specific result that semantic content cannot communicate as clearly.

The retired hand-built SVG favicon was also removed. The current KH mark keeps
the personal monogram dominant, uses the broken orbit and small arrows only as
a light directional inheritance, and intentionally omits the site's vermilion
revision color so the identity stays calm against warm cream.
