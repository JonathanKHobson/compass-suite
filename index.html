About the Compass Suite

The Compass Suite is a family of local-first AI helpers. Each Compass gives an AI assistant a bounded job, a clearer workflow, and a stronger standard for when to ask, retrieve, validate, or stop.

What They Share

These tools favor narrow workflows, local files, clear install paths, conservative claims, and validation before polished output. They are designed to help a host AI work more carefully instead of simply sounding more confident.

What They Do Not Do

They do not replace human judgment, guarantee truth, or make private material public. Alpha products may change quickly, so this suite page describes them lightly until their public contracts settle.

Why a Storefront Exists

Each Compass has its own home page and release notes. This page gives the suite a single front door so people can choose the right tool without learning every project history first.

Tool Overview

Critical Compass

Use it when the question is whether a text should be trusted, revised, verified, reframed, or handled with more care.

Prompt Compass

Use it when an AI instruction is vague, brittle, too broad, missing constraints, or aimed at the wrong model or surface.

UX Heuristics Compass

Use it for structured heuristic reviews of screens, captures, visible usability issues, severity, and stakeholder-ready audit output.

TTRPG Compass

Use it for session sparks, table-ready creative material, and support that keeps rules and prep from breaking the flow.

Research Compass

Use it to frame a research-shaped question, choose the right evidence lane, and keep private notes separate from public sources.

Job Application Compass

Use it privately to map a job description to verified evidence and produce application materials without inventing claims.

Privacy Boundary

Job Application Compass stays locked until a public scrub proves that private career material, contact details, application history, private links, and local-only evidence files are not exposed.

Install Guide

Most Compass tools ship in a few formats. Pick the one that matches how you use AI today. You can usually install more than one format if you want both a tool connection and a prompt-only fallback.

Claude Code / Cowork Plugin

Use this packaged plugin zip for Claude Cowork or Claude Code when you want the full tool connection.

  1. Download the plugin zip from the product card.
  2. Open the dedicated product page in the new tab for product-specific instructions.
  3. Follow the host app's current plugin install flow.

Claude Desktop Extension

Use the MCPB or extension file when you already have Claude Desktop installed.

  1. Download the desktop extension file.
  2. Open Claude Desktop settings and find Extensions.
  3. Install the file, approve the standard local-extension warning, then test the product's get-started prompt.

Skill File or Skill Zip

Use this when you want the prompt-only version or when the host does not support the MCP connector yet.

  1. Download the skill file or skill zip.
  2. Add it through your host app's skill import flow.
  3. Use the product page's starter prompt to confirm the skill is active.

Source Zip

Use this for source review, technical install, or local inspection before trusting a package.

  1. Download the source zip.
  2. Review the files and checksums.
  3. Follow the product page's source-install instructions rather than guessing from the suite page.

FAQ

Plain-language answers for people who are still mapping the AI tooling landscape.

What is an MCP?

MCP means Model Context Protocol. It is a way for an AI host to connect to tools, local data, and structured workflows. In plain terms: it lets the AI ask a local tool to do a bounded job instead of improvising everything in chat.

Learn more about MCPs

What is a skill?

A skill is a packaged instruction set the AI can read and follow. It is usually lighter than an MCP because it may not expose local tools or databases, but it can still guide the AI through a workflow.

What is Claude Desktop?

Claude Desktop is Anthropic's desktop app for using Claude on your computer. It can work with local extensions and MCP connectors when those are installed and approved.

What is Codex?

Codex is a coding-oriented AI environment. It is useful when a Compass needs local files inspected, packages validated, tests run, or source installs handled carefully.

How are Claude, Codex, and Claude Desktop different?

Claude is the AI model family. Claude Desktop is an app for using Claude on your computer. Codex is a coding-agent environment with strong local file and command-line workflows.

What does local-first mean here?

Local-first means the product is designed to run from files and tools on your machine when possible. It reduces dependence on hosted services, but you still need to review any third-party package before installing it.

Why are some Compass downloads locked?

Alpha products change quickly. A download appears here only after the product has a public-safe page, package, checksum, and private-data boundary review. Critical Compass, Prompt Compass, and UX Heuristics Compass currently meet that bar.

Do I need a GitHub account?

No. Public download buttons point directly to release files. GitHub is where the public files are hosted.

Individual Compass pages remain the authority for product-specific docs, checksums, examples, and release notes.
