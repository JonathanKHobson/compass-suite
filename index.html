04 / Install

Install the format your host expects.

Use each product page as the authority for current files and checksums. These screenshots document tested Claude paths; Codex collections install from extracted skill folders.

01Claude plugin ZIPShow steps
  1. Open Claude and choose Customize.
  2. Open personal plugins and choose the add menu.
  3. Upload the local plugin ZIP, then verify the installed collection.
02Claude Desktop extensionShow steps
  1. Download the .mcpb release asset.
  2. Open Claude Desktop settings and choose Extensions.
  3. Drop in the file, review its permissions, and confirm installation.
03Claude skill fileShow steps
  1. Open Claude Skills.
  2. Choose the add button, then upload a .skill file.
  3. Confirm the skill appears in the installed list.

05 / Builder

Built from real work. Kept small on purpose.

I’m Jonathan Kyle Hobson, a UX researcher, product strategist, teacher, game master, and AI-tool builder. I make these tools when a repeated task needs a clearer boundary, a better handoff, or proof that the work actually finished.

The library will change. The rule stays the same: one tool should have one bounded job, a visible limit, and a result a person can inspect.
